# Vynl

An alternative offline and online music player with no ads. Vynl lets you enjoy your local music library and stream music from YouTube, all in one clean, lightweight app.

---

## Features

- **Ad-Free Experience** – Listen to your music without interruptions.
- **Offline Mode** – Play music stored locally on your device.
- **Online Mode** – Stream music directly from YouTube.
- **Clean UI** – Simple and intuitive interface built with Flutter.
- **Cross-Platform** – Supports Android, iOS, and other platforms via Flutter.

---

## Tech Stack

- **Framework:** [Flutter](https://flutter.dev)
- **Languages:** Dart, Kotlin, Swift, C/C++
- **Build System:** CMake

---

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)
- Android Studio / Xcode (for emulation or device deployment)
- A valid `ANDROID_HOME` / Xcode setup for mobile builds

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RyannKim327/Vynl.git
   cd Vynl
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

For help getting started with Flutter development, check out the [official Flutter documentation](https://docs.flutter.dev/).

## Permissions

Vynl may require the following permissions depending on your platform:

- **Storage / Media Access** – To read local audio files for offline playback.
- **Internet** – To stream music from YouTube in online mode.
